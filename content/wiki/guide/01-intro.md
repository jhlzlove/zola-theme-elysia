Elysia 的用法很直接：Zola 读取 `content/` 的 Markdown，模板负责呈现为博客、Wiki 或独立页面。详细功能与目录示例已在置顶文章《你好，Elysia》中列出，本章只说明如何使用本指南。

## 适合与不适合

- 适合：以文字为主的博客、持续维护的文档 / Wiki、需要分类与归档的站点。
- 不适合：强依赖封面图卡片流、或重度依赖 Headless CMS 的场景（需自行扩展）。

## 指南结构

| 章 | 主题 | 产出 |
| --- | --- | --- |
| 01 | 认识 Elysia（本章） | 判断是否适用，明确阅读路径 |
| 02 | 快速安装 | 本地 `zola serve` 跑起来 |
| 03 | 配置详解 | `zola.toml` 每一项可复制配置 |
| 04 | 部署网站 | 发布到 GitHub Pages / Netlify / 私有服务器 |
| 05 | Markdown 与组件 | Front Matter、Markdown 与组件（附写法与效果） |

## 如何阅读

- 新用户：按 01 → 02 → 03 顺序，本地预览后再看 04 与 05。
- 已有 Zola 站点：将主题作为子模块引入后，直接看 03 与 05。
- 只想写作：直接看 05，复制 Front Matter 与组件即可。
