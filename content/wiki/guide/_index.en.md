Elysia is a blog theme for [Zola](https://www.getzola.org/) providing blog listings, Wiki sections, archives, categories, tags, a heatmap, search, comments, a resume page, and reusable Markdown components.

Follow the guide in order without needing theme internals. For a quick overview of features and layout, see the pinned post *Hello, Elysia*.

1. **Meet Elysia**: decide fit and reading path.
2. **Quick install**: preview locally and see where files belong.
3. **Configuration**: every `zola.toml` option with copy-ready snippets.
4. **Deploy the site**: build static files and publish to GitHub Pages or another host.
5. **Markdown and components**: Front Matter, Markdown, and components (syntax plus rendered output).
